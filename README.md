# Teacher Viacava — landing page

Landing page responsiva em React, TypeScript e Vite para a marca Teacher Viacava.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```

## Conteúdo editável

- Informações do negócio e mensagem do WhatsApp: `src/data.ts`
- Conteúdo e estrutura da página: `src/App.tsx`
- Design tokens e estilos responsivos: `src/styles.css`
- Foto: substitua o bloco `.portrait-placeholder` por uma imagem autêntica do professor quando o arquivo estiver disponível.

O espaço de depoimentos foi mantido como uma prévia editorial, sem relatos ou nomes fictícios. Substitua-o apenas quando houver depoimentos reais autorizados.
